# Passe de réalisme, chargée par l'outil MCP

1. Appelle l'outil `charger` du serveur MCP `studio` de ce plugin (nom complet :
   `mcp__plugin_essai_studio__charger`) avec `nom` = `base/passe-realisme`.
2. Suis exactement la procédure qu'il renvoie.
3. Si l'outil n'est pas disponible dans cette session, dis-le tel quel : c'est le résultat de
   l'essai. N'essaie pas d'autre voie.

Réglage du plugin essai, pour la question 7 : `dossier_rendus` vaut « ${user_config.dossier_rendus} ».
Signale cette valeur au membre.
